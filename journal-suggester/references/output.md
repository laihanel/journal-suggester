# Recommendation format

Adapt length to the request. Default to 3–5 verified choices and avoid forcing a fifth weak option. Start with the recommendation and priority rationale, then state the manuscript profile and meaningful assumptions briefly. Use a compact comparison followed by evidence notes.

Suggested columns (omit unrequested metrics or split an unwieldy table):

| Journal | Scope fit and main concern | Metrics/indexing | Timing | OA and estimated payable cost | Evidence/eligibility |
| --- | --- | --- | --- | --- | --- |

For each journal, supply:

1. Official name and verified ISSN/eISSN when available; official scope/instructions links.
2. Why the manuscript fits, tied to explicit scope and 2–3 related papers where available. Link DOI/article, year, topic/method overlap, and what was examined. State if evidence is limited to titles.
3. A concrete potential mismatch or editorial requirement; do not invent a concern if none is found. "No specific mismatch identified from the reviewed material" is acceptable with the evidence limits.
4. Requested metrics with data year and category, and required indexing status with coverage evidence. Unknown stays unverified.
5. Timing with exact endpoint, units, median/mean, and reporting period/population if available. Do not write an unlabeled "review: 10 days."
6. OA route and license/embargo when relevant, public list APC, other mandatory fees, and estimated payable amount. Preserve currency and conditions.
7. Institutional agreement status if assessed, supporting library/title-list links, remaining eligibility conditions, and any quota/approval uncertainty.

Place source links next to the supported claims; include the access date once for a same-day research run and policy/metric dates separately. Distinguish direct index verification from a publisher's reported metric. Show source conflicts where material rather than hiding them in a footnote. Report whether publisher suggestions were directly queried, imported, or unavailable when the user requested them.

End with a practical submission order if the evidence supports one, or alternative choices by priority if tied. Explain what must be verified before submission. Historical timing is not a deadline guarantee. Acceptance rates, when officially available, describe a population and are not personal acceptance probabilities.

If evidence is insufficient, use separate provisional candidates and unresolved checks. If no candidate meets a binding requirement, say so, identify the bottleneck, and suggest the smallest relaxation for the user to consider. Do not automatically apply that relaxation.
